# Dissertation Source Code

This repository contains the source code for the dissertation submitted by Ibrahim Gillani.

- `run_model_on_sketch.py` — the sketch-to-heightmap generation and repair pipeline.
- `grid_traversability.py` — the custom pathfinding system and brush tool.

**NOTE: This code is for REVIEW only.** Neither file will run standalone, as several dependencies are required, including the InfiniteDiffusion model, UE5 project connections, and sketch assets, none of which are included in this repository.
